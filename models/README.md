# Model Releases

The model files are organized by four model families and three generation tasks.

## Directory Structure

~~~text
models/
├── cnn/
│   ├── path_loss/
│   ├── beam_power/
│   └── beam_tracking/
├── lstm/
│   ├── path_loss/
│   ├── beam_power/
│   └── beam_tracking/
├── mlp/
│   ├── path_loss/
│   ├── beam_power/
│   └── beam_tracking/
└── transformer/
    ├── path_loss/
    ├── beam_power/
    └── beam_tracking/
~~~
