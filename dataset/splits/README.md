# Splits

This directory stores text or JSON files that define reproducible input and test subsets for inference.

Planned split files include:

- 'suburban_daytime_input.txt'
- 'suburban_daytime_test.txt'
- 'urban_daytime_input.txt'
- 'urban_daytime_test.txt'
- 'urban_nighttime_input.txt'
- 'urban_nighttime_test.txt'

The split files contain references to data samples. They do not contain the samples themselves.
