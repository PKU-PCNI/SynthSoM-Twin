# Metadata

This directory stores dataset documentation and file indexes.

Planned files include:

- 'dataset_description.json': Dataset-wide description and version information.
- 'scenario_metadata.json': Scenario-specific metadata for SC31, SC32, and SC33.
- 'file_manifest.csv': File paths, sizes, checksums, and preprocessing status.

The complete data is distributed through the Baidu Netdisk source described in [dataset/README.md](../README.md).
