# Urban Nighttime Raw Data

The urban nighttime V2I dataset corresponds to SC33. It is distributed through the permanent Baidu Netdisk directory below.

## Download Information

- Baidu Netdisk directory: [Urban Nighttime](https://pan.baidu.com/s/1wGR4QxGfyCCPRupGFwkbnQ)
- Extraction code: `e0tu`
- Validity: Permanent
- Netdisk path: `/SynthSoM-Twin/dataset/raw/urban_nighttime/`
- Local placement: `dataset/raw/urban_nighttime/`

## Directory Structure

~~~text
urban_nighttime/
├── communication/
│   └── mmwave_60ghz/
├── sensing/
│   ├── rsu/
│   └── vehicle/
└── real_world/
~~~

Place the downloaded files under the matching directories above. Preserve the complete scenario name, package names, frame indices, sensor associations, and transmitter/receiver correspondence during data access and preprocessing.

See [dataset/README.md](../../README.md) for the complete release table and scenario definitions.
