# Suburban Daytime Raw Data

The suburban daytime V2I dataset corresponds to SC31. It is distributed through the permanent Baidu Netdisk directory below.

## Download Information

- Baidu Netdisk directory: [Suburban Daytime](https://pan.baidu.com/s/1C4c9BRjU3hqhsZ5S3ey_3g)
- Extraction code: `e6qa`
- Validity: Permanent
- Netdisk path: `/SynthSoM-Twin/dataset/raw/suburban_daytime/`
- Local placement: `dataset/raw/suburban_daytime/`

## Directory Structure

~~~text
suburban_daytime/
├── communication/
│   └── mmwave_60ghz/
├── sensing/
│   ├── rsu/
│   └── vehicle/
└── real_world/
~~~

Place the downloaded files under the matching directories above. Preserve the complete scenario name, package names, frame indices, sensor associations, and transmitter/receiver correspondence during data access and preprocessing.

See [dataset/README.md](../../README.md) for the complete release table and scenario definitions.
