# Urban Daytime Raw Data

The urban daytime V2I dataset corresponds to SC32. It is distributed through the permanent Baidu Netdisk directory below.

## Download Information

- Baidu Netdisk directory: [Urban Daytime](https://pan.baidu.com/s/11LJs57TgqvGYkwLF88ZQVw)
- Extraction code: `pew6`
- Validity: Permanent
- Netdisk path: `/SynthSoM-Twin/dataset/raw/urban_daytime/`
- Local placement: `dataset/raw/urban_daytime/`

## Directory Structure

~~~text
urban_daytime/
├── communication/
│   └── mmwave_60ghz/
├── sensing/
│   ├── rsu/
│   └── vehicle/
└── real_world/
~~~

Place the downloaded files under the matching directories above. Preserve the complete scenario name, package names, frame indices, sensor associations, and transmitter/receiver correspondence during data access and preprocessing.

See [dataset/README.md](../../README.md) for the complete release table and scenario definitions.
